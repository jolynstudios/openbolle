# openBolle case v1

**Start with the two single-colour plates.** For one case, print `openbolle-case-v1-1x-zwart.3mf` in black (front shell and board holder). Then print `openbolle-case-v1-1x-kleur.3mf` in orange, blue or your chosen colour (rear shell and button). Use the matching `3x` pair for three cases. Each of these jobs uses one spool.

The plain `1x` and `3x` plates contain all four parts per case for a single-colour job. The `two-colour` plates contain the same parts with two colours assigned. Check the spool mapping in your slicer.

Use a clean 256 × 256 mm bed and the printer, plate and filament profiles that worked for your individual parts. Keep the supplied positions and orientations. Print by layer. Add a **5 mm outer brim** to the board holder and rear shell. In the preview, check the brims against your printer's usable area and leave room for any purge tower. If the tower will not fit, use the separate colour plates. Watch the holder's first layer. Stop if an edge lifts.

The small screw spacers print separately. In `openbolle-case-v1-stl.zip` from [Releases](https://github.com/jolynstudios/openbolle/releases), choose `5_afstandsring_met_rand.stl` for a spacer with a snap-off brim, or `5_afstandsring.stl` for the plain one. Print three per case, plus any spares. The zip also holds the four main parts as individual STLs.

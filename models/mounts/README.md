# Mounts

Mounts hold Bolle in the car. They are sorted by car brand, then by model and position. Every mount fits case v1.

| brand | mount | fits |
|---|---|---|
| Tesla | [model-3-y-dashboard](tesla/model-3-y-dashboard/) | Tesla Model 3 and Model Y, on the dashboard |

Print the click test in a mount's folder first, then the mount itself.

Is your car missing? Ask on [openbolle.nl](https://openbolle.nl) or open an [issue](https://github.com/jolynstudios/openbolle/issues).
